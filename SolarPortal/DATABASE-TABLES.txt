TABLE                 ENTITY                NOTES

IncConnections        IncConnection         DbSet registered, but no ToTable()
                                            call and absent from the migration
                                            snapshot. Falls back to the EF
                                            convention name (DbSet property).
                                            Solar connection registered by an
                                            INC/Installer worker.

IncWithdrawals        IncWithdrawal         Source comment states it maps to a
                                            pre-existing IncWithdrawals table.
                                            Does not derive from BaseEntity,
                                            so no CreatedAt/UpdatedAt/IsDeleted.

WARNING
  These two are neither in the migration snapshot nor marked
  ExcludeFromMigrations(). Two consequences:
    1. If the tables do not already exist in the target database, queries
       against them fail at runtime.
    2. The next `dotnet ef migrations add` will try to emit CREATE TABLE for
       both. If the tables already exist in the live DB, that migration will
       fail on apply.
  Fix: either add them to a migration deliberately, or mark them
  ExcludeFromMigrations() alongside the m_* legacy tables.
